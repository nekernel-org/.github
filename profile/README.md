# NeKernel.org

## Abstract:

A collection of freely available C or C++ system software for companies and teams alike, NeKernel boots and runs as of 2026.

In addition of the primers and wiki, there are guides made to teach you and your team how to develop on NeKernel sources.

## The NeKernel Framework:

We live by those three principles at NeKernel.org:

- Each **Repository** must be built with modularity at its core.  
- Each **Component** must be designed as cleanly extensible.  
- Each new **Software Component** must be integrated without rewriting the codebase as a whole.
