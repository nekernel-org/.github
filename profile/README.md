## About Ne.app

Ne.app is a systems software company that distributes the [NeSystem](https://src.nekernel.org) and proprietary [Ant](https://ant.ne-app.eu) OS system distributions.

In addition to that, there are primers and wiki, which teaches you how to use the NeSystem and Ant by Ne.app.
