# NeKernel.org

## Abstract:

A collection of freely available C or C++ system software. 

We believe in free software as the only way to develop, and deliver systems software.

### The NeKernel Development Framework:

You must follow those rules in order to contribute to NeKernel projects:

- Each **Repository** must be built with modularity at its core.  
- Each **Components** must be designed as cleanly extensible.  
- New **Software Components** must be integrated without rewriting the codebase as a whole.
